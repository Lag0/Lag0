### What I'm building

**UVI One** (private, pre-revenue)<br>
Multi-tenant WhatsApp AI assistant for clinics.
- Next.js dashboard, Node/Bun bot service, PostgreSQL with Drizzle migrations
- RAG over clinic knowledge and Google Calendar scheduling
- Human/AI handoff: staff take over with one click, and on handback the AI summarizes the conversation into the patient profile
- Idempotent webhooks with deterministic event ids
- One Docker Compose stack per clinic on a VPS
- Every LLM call logged with tokens, latency and cost

**[pi-tube](https://github.com/Lag0/pi-tube)** · [`@syxs/pi-tube`](https://www.npmjs.com/package/@syxs/pi-tube)<br>
TypeScript CLI that turns public media into transcripts AI agents can use. Tested with Vitest, published to npm by GitHub Actions.

**Fala AI** (back in active development)<br>
WhatsApp message transcription SaaS. Its first version reached 15 paying customers.<br>
Next.js, Stripe subscriptions, Prisma on Neon, webhooks, TanStack Query, Resend.

**SYXS Legal** (private, in use)<br>
Legal case monitoring for a family office. Pulls updates from the DataJud API and scrapes eproc, then notifies the team on Discord.

**[MedAbrigo](https://github.com/Lag0/fiap-medabrigo)**<br>
FIAP Global Solution 2025. Helps people in natural disasters find the nearest shelter that has the medicine they need, using geolocation.
